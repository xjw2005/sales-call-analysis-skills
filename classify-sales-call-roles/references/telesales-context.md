# 当前场景：达能门店运营电销（优先于通用拜访规则）

我方电销人员通过电话联系门店，开展皇冠店政策回访、核心店 SPC 调研、领熠/亲熠分销促单。目标是记录门店反馈，不是推断录音外的成交或经营事实。

## 身份判断

- 销售：我方外呼人员。可能自称品牌渠道专员、回访专员；即使只询问政策知晓、积分操作或售后需求，没有推销，也属于销售。
- 客户：代表受访门店接听、回答或提出业务需求的人，包括老板、店长、店员、代接后参与答复者。店员不是旁人的默认条件；接听者说“老板不在，我是店员”仍可属于客户。
- 旁人：无关背景插话或电话系统提示音。不能把“喂、你好、再见”本身当作旁人证据。
- 保留真实 speaker 数量；允许两个客户接力、一人被 ASR 分成多个 ID。不能按 speaker 0/1、先开口、声音性别、说话时长强制分配角色。
- “你们销售没来”“业务员答应给我配额”中的销售是被提及的第三人，发言者仍可能是客户；提及销售、政策、产品不等于本人是销售。
- 画像中的关键词分数只是线索。根据自我介绍、问答方向、我方/你方指代和前后文综合判断。销售复述客户问题、客户转述销售话术不代表角色漂移。
- 录音缺少明确身份线索时，不得用默认示例凑齐双方；遵守现有 JSON 格式，以 fallback 旁人保留不确定片段，交人工核验。旁人包含未能确认身份的片段，不等于已证明是背景噪音。

## 后续标签的证据边界

- 电销介绍政策不证明客户原本知晓；客户简短“嗯、好”不自动证明知晓、兴趣或合作意向。
- 被询问是否缺配额，不等于实际缺配额。客户具体回答是主要依据；推断须按该项目标签定义执行。
- 门店服务需求不等于已派单、已上门或已解决；保留否定、条件、数量、时间和未确认状态。
- 不把短通话或拒绝进货直接判成没有业务价值；“不卖这个”“已经关店”“缺配额”等短答可能是关键反馈。

当前项目对外标签为「渠道专员／客户／旁人」。内部JSON仍按既有schema使用「销售」代表我方外呼人员，显示层自动改为「渠道专员」。正文提及的线下销售是被谈论的人，不据此改变当前说话人身份，也不替换正文称谓。
