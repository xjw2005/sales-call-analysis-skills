# categories — 业务类目

## 双口径规则（用户 2026-08-05 决策，不要推翻）

1. **打标口径**：分析模块的「关心类目打标」按原有 **9 个类目**（价格敏感/物流时效/控价防窜/培训支持/售后保障/合作模式/利润空间/系统工具/其他），飞书多选字段与流水线白名单**不改**。
2. **内容口径**：知识库内容按需求文档的 **14 个类目**收集（定义/边界/正反例），供品牌方供稿，作为类目知识储备。
3. `类目总表.md` 维护 9↔14 映射；若将来打标升级，映射表即依据。

## 收录范围

- `类目总表.md`：14 类总览 + 9↔14 映射 + 相邻类目辨析索引
- 14 个类目条目，每类一个文件：定义、识别线索、边界、正反例、与相邻类目辨析

## 排除边界

- 类目打标的输出结构/判断逻辑——属流水线模块设计，不进知识库
- 门店实例事实——归 `archive/`

## 生命周期与修改检查单

- 新增条目：新开 ID `categories-<topic>-<seq>`、`version=1`、`status=active`；文件 `version` +1。
- 修改条目：**ID 不变**，条目 `version` +1，文件内 `## 变更记录` 追加一行。
- 作废条目：**禁止物理删除**，`status: superseded` + `superseded_by: <新id>`。
- 提交前跑：`python scripts/knowledge_check.py --root <本仓库>\knowledge`。
