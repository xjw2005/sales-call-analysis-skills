# archive — 沉淀档案

## 收录范围

**机器生成区**，与四个静态参考库性质不同：随每次录音分析自动沉淀，不做人工条目审查。

- `stores/`：门店档案快照——一个门店一个文件，按门店编号累积；**单次录音快照，不跨录音合并**（铁律 7）；门店经营背景（新客少/客流低/房租高/快做不下去等）沉淀进档案「经营背景」，默认不触发行动
- 销售客户库经验：后续按需扩展

## 排除边界

- 静态参考知识（法规/产品/竞品/业务规范）——归各静态库
- 分析输出本身——回写飞书多维表，此处只存档案快照

## 生命周期

- 生成：流水线分析后自动追加/更新快照（带 record_id 溯源）
- 注入：**默认不注入模型**（铁律：不跨录音合并、不引用历史信息）；是否注入是待定决策，先做人查

## 消费模块

默认不注入；人工/AI 助手查阅。
