# 唯一任务：销售金句

提取 0～5 条真正可复用的销售表达，不强行凑数。

- 只能引用纠正后角色为销售的发言。
- 多个 `evidence_ids` 必须数字连续、同一角色且属于同一表达，禁止跨客户发言拼接。
- 优先选择澄清需求、重构问题、量化价值、承接异议或推动下一步承诺的表达。
- 泛化保证、普通产品介绍或没有具体方法的表述不算金句。
- `polished_quote` 是基于证据原话整理出的可读金句，不是逐字转录：
  - 删除“嗯、啊、呃、诶、嘛、那个”等无意义语气词。
  - 删除口吃、重复词和无效停顿，如“都有都有”“老板老板老板”“你你你”。
  - 补充必要标点，轻度调整语序，使表达完整、自然、便于复用。
  - 保留原话的核心意思、产品名、数字、条件和承诺边界；不得新增卖点、事实、数字、保证或客户态度。
  - 不要写发言 ID、时间戳、外层引号或分析说明；长度控制在 6～200 字。
- 原话本身已经简洁时可以保留，不要为了改写而改变措辞。
- 只有存在明确客户发言时才填写 `reaction_ids`，否则必须为空。

示例：

- 原话：“这个嘛我看到你们都有都有跟渝欧合作就是那些纽康特啊春竹啊这些你们都有在做所以的话看一下像这些品的话有没有兴趣呢这种嘛”
- `polished_quote`：“我看你们有跟渝欧合作，比如纽康特、春竹这些，所以想了解一下，这些产品你们是否有兴趣？”

```json
{
  "_scope": {},
  "quotes": {
    "items": [{
      "evidence_ids": ["U0001"],
      "polished_quote": "",
      "speaker_name": "不知道时写录音未提供姓名",
      "scene": "",
      "problem": "",
      "method": "",
      "value": "",
      "reaction_ids": []
    }]
  }
}
```
