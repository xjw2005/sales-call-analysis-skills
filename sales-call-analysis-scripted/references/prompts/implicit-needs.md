# 唯一任务：隐性需求与顾虑

参考知识库（产品知识）仅用于理解客户提到的产品与生成假设方向；每条隐性需求仍需录音内客户证据支撑，不得据知识条目补写。

只提取由多条客户证据支持、但客户没有直接完整说出的深层需求或顾虑假设。

- 提取 0～5 条，可信度为高/中/低。
- 高/中可信度每条至少两条客户证据；高可信度应有跨场景一致证据。单一弱信号最多只能形成低可信度，仍需至少一条客户证据。
- 先完成 `_scope.role_corrections` 和 `_scope.exclusions`，再选择证据；`evidence_ids` 只能引用纠正后仍为“客户”且未被排除的发言。不得引用已纠正为销售/旁人的发言。
- 若同一个发言 ID 内同时混入销售问句、销售复述和客户短答，整条视为角色不可分，不得把整条纠正为客户，也不得作为客户证据；不足两条可确认客户证据时不生成该项，全部不足时输出空数组。
- 销售对客户经营情况的推测、复述或确认性问句不能替代客户原话。
- 不从沉默、未打断、认真倾听或销售单方面介绍推断客户认同。
- 禁止生成建议验证问题或待验证点。

```json
{
  "_scope": {},
  "implicit-needs": {
    "items": [{
      "hypothesis": "",
      "confidence": "高|中|低",
      "evidence_ids": ["U0001", "U0002"],
      "logic": ""
    }]
  }
}
```
