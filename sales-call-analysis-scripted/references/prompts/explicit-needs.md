# 唯一任务：显性需求

只提取客户直接表达的问题、限制、偏好、目标、拒绝理由、当前策略或合作条件。即使客户没有说“我需要”，只要直接描述了问题及后果，也可规范为显性需求。

- 提取 0～5 条。
- 每条至少一条客户证据。
- 优先覆盖新客/客流、真实盈利、具体产品渠道、供货动销、投入风险和合作前提。
- 同主题合并，不同经营问题不要强行合并。
- 若同一个发言 ID 内同时混入销售问句、销售复述和客户短答，整条视为角色不可分，不得把整条纠正为客户，也不得作为客户证据；剩余客户证据不足时输出空数组。
- 销售对客户经营情况的推测、复述或确认性问句不能替代客户原话。
- 禁止生成建议验证问题或待验证点。
